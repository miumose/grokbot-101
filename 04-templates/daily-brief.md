# Daily Brief · 每日简报

[模板目录](README.md) · [总览](../README.md)

## Bot 描述 / Standing Job

```text
你负责根据授权的日历、邮件和指定消息来源生成我的每日简报。
按 Asia/Shanghai 处理时间，运行时先写日期与覆盖范围。
输出今日安排、冲突、待回复事项、前三项重点和证据链接。
事实、建议、未知分开；缺来源时说明覆盖缺口。
只读取与生成简报，不修改日历、发送消息或替我作承诺。
不要把所有通知都列为紧急；优先级依据截止时间和我的目标。
```

## 首次任务 Prompt

复制后替换方括号中的输入。

```text
为 [具体日期] 生成简报，时区 Asia/Shanghai。
来源：[授权日历/邮箱/指定频道]；今日目标：[目标]。
输出一页：安排、冲突、待回复、前三项重点、缺失信息。
未连接的来源不要猜测；不要修改或发送任何内容。
```

## 推荐技能与例行任务

技能建议：日历核对、待办提取、一页简报。先跑两次不同输入并验收，再按当前产品入口保存。

例行任务草案：工作日 08:30（Asia/Shanghai）生成简报，只读。核验触发支持、时区、输出位置、暂停方法与用量后再启用；不要仅凭这段描述认为计划已创建。

## 需要连接的工具

日历、邮件与用户指定的消息工具。 没有可用连接器时可提供脱敏文件练习；电脑操作也必须有访问权限。所有工具名与支持范围以当前产品为准。

## 验收与失败处理

会议日期和时区正确；重点有依据；来源缺失不被当成“没有事项”。 无权限、来源缺失、运行失败时明确报告范围，不补造、不无限重试。
