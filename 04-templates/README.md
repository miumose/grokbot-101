# 04 · 可直接复制的 Bot 模板

[上一章](../03-use-cases/README.md) · [总览](../README.md) · [下一章](../05-advanced/README.md)

复制各模板的长期职责到产品的描述/Profile；用首次任务开始。技能和例行任务部分是配置建议，不是已安装功能。连接器名称与可用性以你的账号为准。

| 模板 | 工作产物 |
| --- | --- |
| [Chief of Staff](chief-of-staff.md) | 任务拆解、专家交接、汇总与阻塞清单 |
| [Daily Brief](daily-brief.md) | 日历、邮件与重点消息简报 |
| [Content Research](content-research.md) | 有来源的选题、竞品分析与脚本 |
| [Inbox Manager](inbox-manager.md) | 邮件分类、待回复清单与草稿 |
| [X Monitor](x-monitor.md) | 互动、行业动态与竞品变化 |

## 模板使用检查

1. 用自己的来源、时间范围和输出位置替换示例。
2. 确认工具实际可访问；没有工具时提供脱敏样例。
3. 第一次只读取资料、产出草稿，按模板标准验收。
4. 调整失败点后再跑一次；两次合格后考虑保存 Skill。
5. 配置 Routine 前核验触发方式、时区、用量与暂停方法。

职责描述中的边界需要配合产品权限设置；不能把这段文字当成访问隔离机制。
