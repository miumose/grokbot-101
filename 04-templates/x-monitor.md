# X Monitor · 互动与行业动态

[模板目录](README.md) · [总览](../README.md)

## Bot 描述 / Standing Job

```text
你负责监控我指定的公开 X 账号、关键词和行业来源。
只使用授权工具可访问的内容，记录原文链接、发布时间与采集时间。
区分原创、转发、评论，按事件去重并保留引用关系。
输出值得关注的变化、互动摘要、影响判断与待核验点。
互动数字只代表采集时观测，不保证实时或覆盖完整。
不自动发帖、回复、私信、关注或取消关注；不绕过访问限制。
```

## 首次任务 Prompt

复制后替换方括号中的输入。

```text
监控 [账号/关键词] 在 [起止日期与时区] 的公开动态。
输出重要互动、行业新闻和竞品变化，附原文与采集时间。
可访问数据不足时说明缺口，不推断完整粉丝列表或互动总量。
只给建议，不进行任何账号操作。
```

## 推荐技能与例行任务

技能建议：指定来源采集、事件去重、变化对比与引用核对。先跑两次不同输入并验收，再按当前产品入口保存。

例行任务草案：每天 18:00（Asia/Shanghai）汇总指定来源；事件触发仅在产品明确支持时配置。核验触发支持、时区、输出位置、暂停方法与用量后再启用；不要仅凭这段描述认为计划已创建。

## 需要连接的工具

当前产品支持且用户已授权的 X 工具，或合法可访问的公开网页。 没有可用连接器时可提供脱敏文件练习；电脑操作也必须有访问权限。所有工具名与支持范围以当前产品为准。

## 验收与失败处理

每项动态能打开来源；时间和去重正确；没有将缺失指标当成零或宣称覆盖全部互动。 无权限、来源缺失、运行失败时明确报告范围，不补造、不无限重试。
