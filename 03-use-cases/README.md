# 03 · 实战：从任务到可检查的结果

[上一章](../02-core-concepts/README.md) · [总览](../README.md) · [下一章](../04-templates/README.md)

以下是适合入门的场景选择，不是 X 热度榜。本仓库没有取得可比较的互动量样本，因此不使用「最高热度」「爆款」作为事实。

| 场景 | 输入与工具 | 交付与验收 | 起步模板 |
| --- | --- | --- | --- |
| Inbox Triage | 指定邮箱、时间范围 | 分类表+草稿，抽查原邮件 | [Inbox Manager](../04-templates/inbox-manager.md) |
| Daily Brief | 日历、邮件、重点消息 | 今日重点+冲突，核对时间 | [Daily Brief](../04-templates/daily-brief.md) |
| Meeting Prep | 会议、参会者、允许读取的资料 | 一页背景与待决策项，有来源 | Daily Brief |
| YouTube/短视频选题 | 渠道、受众、竞品公开链接 | 5 个选题与脚本，事实可追溯 | [Content Research](../04-templates/content-research.md) |
| 内容监控 | 指定账号、关键词、时间范围 | 候选内容+采集时指标，无指标不排名 | [X Monitor](../04-templates/x-monitor.md) |
| Prospecting | 客户画像、公开企业资料 | 候选客户+匹配依据，不猜联系方式 | Content Research |
| Outbound/Follow-up | 已授权 CRM、历史沟通 | 邮件草稿+跟进清单，不自动发送 | Inbox Manager |
| Bug 复现/PR Review | 仓库、版本、复现步骤、测试命令 | 复现记录或审查意见，有执行证据 | [工程练习](#工程练习bug-复现与-pr-review) |
| 竞品/行业监控 | 监控清单、可信来源 | 变化+影响+原文，不把转载算多条证据 | X Monitor |
| 团队协作 | 任务清单、专家职责、交接规则 | 汇总报告+阻塞项，责任明确 | [Chief of Staff](../04-templates/chief-of-staff.md) |
| 旅行规划 | 日期、预算、偏好 | 候选行程+查询时间，不代购 | Content Research |

| 健康追踪 | 用户选择提供的记录 | 趋势整理，不诊断或代替专业建议 | Daily Brief |

## 完整练习：准备一次会议

```text
为明天 14:00（Asia/Shanghai）的项目会议准备一页简报。
我会提供会议日期、议题、参会者和可用资料，请先检查是否齐全。
输出：会议目标、背景事实、三项待决策问题、建议议程、未决信息。
每条背景事实附来源；资料冲突时列出两种说法。
不要修改日历或联系参会者。
```

验收：日期不靠“明天”猜测；背景来自授权资料；建议与事实区分；未决信息可交由参会者确认。

## 完整练习：选题研究到短视频脚本

```text
受众：第一次接触 AI 队友的小团队负责人。
主题：Chief of Staff + 专家 Bot。
依据我提供的公开链接，给出 5 个选题，选 1 个写 60 秒口播稿。
每个选题附受众痛点、内容角度、证据链接、待核验主张。
只有取得同一时间范围、同一平台可比互动指标时，才比较热度。
脚本中不虚构用户案例、效果数字或产品功能，不发布。
```

验收：脚本能追溯事实；观点标为观点；没有“效率提升十倍”等无依据承诺。

## 工程练习：Bug 复现与 PR Review

```text
在我指定的仓库和提交版本上调查这个 Bug。
先阅读仓库说明，确认依赖、测试命令和复现条件。
本次只调查，不修改代码，不部署。
输出最小复现步骤、预期/实际行为、相关日志、执行的测试及退出状态。
无法复现时列出已尝试条件与缺失信息，不宣称修复成功。
```

PR Review 可进一步要求：按严重度列问题，引用文件与行号，解释触发条件；区分实测结果与静态判断。配合 Cursor 或 Cloud Agent 时，明确谁负责编辑、谁负责验收，避免多人同时写同一文件。

## 团队练习：Chief of Staff + 两位专家

给 Content Research 收集公开资料，给 Inbox Manager 整理你提供的脱敏反馈。Chief of Staff 合并“外部趋势”和“真实需求”，输出三项建议与证据。先手动交接跑通，再核验 Group Chat 能否完成同样流程。

完成标准：每项建议能定位到专家产物和原始来源；未解决的分歧被保留；没有擅自对外发布或增加例行任务。
