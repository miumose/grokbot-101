# Grok Bot 101 · 中文入门与实战

从创建第一个 Bot，到建立 Chief of Staff + 专家团队。每章都有可以复制的任务、明确的输出和验收方法。

**适合谁：** 希望用 Grok Bot 整理邮件、准备会议、研究内容、跟进客户或辅助开发的人。前几章不要求编程。

## 快速开始：让第一个 Bot 整理邮件

1. 打开 [Grok Bot 产品入口](https://x.ai/bot)，确认账号有访问权限。
2. 找到新建 Bot 入口；社区教程出现过 `New Chat`、`New → Create new agent` 等名称，以当前界面为准。
3. 命名为「Inbox Manager」，复制 [模板](04-templates/inbox-manager.md) 中的长期职责到描述或 Profile。
4. 如有邮件连接器，按产品流程连接一个你有权使用的邮箱；暂时不连接也可用下方模拟数据练习。
5. 发送下面的任务，检查分类、待回复事项和草稿，再考虑重复运行。

```text
请按 Inbox Manager 的职责整理以下模拟邮件。
时间范围：2026-10-12 至 2026-10-18，Asia/Shanghai。
A：客户问交付日期，希望周三前答复；当前交付日期未确认。
B：订阅资讯，无需回复。
C：同事询问周五会议是否参加；我的日历尚未提供。
输出分类表、需要回复的清单、A 和 C 的回复草稿，以及缺失信息。
不要发送邮件，不要自行承诺日期，不要猜测我的日历。
```

**完成标准：** A/C 列为待回复，B 列为资讯；草稿不捏造交付日期或参会决定；缺失信息单列。这个练习验证任务设计，不验证真实邮箱连接或 Grok Bot 产品能力。

## 使用原则

- 先让一个 Bot 把一个任务做对，再增加工具、例行任务和专家。
- 给出时间范围、来源、输出格式和完成标准；结果必须能检查。
- 多 Bot 的名称或职责不同，不代表文件和登录态隔离。
- 发信、发布、购买、删除、部署等动作明确设置确认边界。Prompt 约束应配合产品权限与 Approval 设置使用。
