# FAQ · 常见错误与避坑

[总览](../README.md) · [进阶](README.md)

## Bot 和普通聊天有什么区别？

本教程关注长期职责、工具操作、工作产物与重复流程。能否实际使用这些能力，需要看当前产品、授权和账号；详见 [基础篇](../01-basics/README.md)。

## 所有 Bot 都有独立电脑吗？

社区资料描述同一用户的 Bot 共用电脑，因此文件与登录态可能互相影响。企业或跨用户隔离范围需官方核验；不要假定按 Bot 名称隔离。

## 能同时运行多个任务吗？

产品并发限制尚未核验。即便可以并发，两个任务也可能争用浏览器、账号或文件。先拆开输出目录；共享资源的操作串行执行，并记录负责人。

## 记忆能记什么，为什么还要重复告诉它？

记忆有助于保留偏好与背景，但本仓库未验证具体存储规则。重要日期、授权边界和事实依据仍应显式提供。发现记错时核对来源并通过产品支持的方式更新。

## 从 ChatGPT/Claude 一键迁移记忆吗？

本仓库没有验证一键迁移。先使用 [审阅后摘要迁移](README.md#memory-管理与迁移)，不要上传完整敏感历史记录。

## 找不到 New Chat / Skill / Routine 入口怎么办？

界面可能因版本和套餐不同而变化。核对 [官方入口](../resources.md)，记录平台、版本和具体缺失入口；不要把聊天里生成的流程说明当成已保存技能或已开启计划。

## 没有连接器怎么办？

先用脱敏样例验证任务。若电脑操作可访问同一资料且你有权限，再评估它是否适合；权限不足时报告阻塞，不尝试绕过。

## 为什么邮件分类看似正常但漏了重要事项？

检查时间范围、分页、搜索条件、账号与线程折叠。抽查原邮件，对齐“需要回复”的标准。输出应该包含覆盖范围和缺失情况，不能只看摘要是否流畅。

## Bot 说完成了，但没有文件或证据？

要求产物路径、来源和执行记录，亲自打开结果。找不到产物就标记未完成。运行命令、看到页面或收到“已处理”都不足以证明成功。

## Routine 消耗很快怎么办？

先暂停你配置的重复任务，查频率、重复扫描和失败重试。降低来源数量、缩短输出，人工跑一次记录实际用量。启用前确认时区和失败处理机制。

## Chief of Staff 不断派任务却不交付？

限制专家名单和交接次数，规定负责人、截止时间、交付格式和验收标准。要求报告阻塞而不是无限拆解；先手动跑通一个小流程。

## 常见误区

| 误区 | 改法 |
| --- | --- |
| 只聊天，没有明确成果 | 要求表格、文件或草稿，并写验收标准 |
| 直接开启高频自动化 | 先人工验收两次，再检查计划配置 |
| 职责写成“帮我做一切” | 限定对象、来源、输出和允许动作 |
| 多 Bot 同时编辑同一文件 | 分目录，设置唯一写入负责人 |
| 把估计或热度写成事实 | 给来源和采集时间，无证据就标未知 |
| 以为职责文字等于权限隔离 | 同时检查工具权限、共享电脑和 Approval |
